# AI Akademie – web

Next.js (App Router) + TypeScript + Tailwind CSS. Zadání v `BRIEF.md`, design v `DESIGN.md`.

```bash
cp .env.example .env.local   # doplňte klíče
npm install
npm run dev
```

- Značka (název, barvy, kontakty): `src/config/brand.ts`, fonty: `src/config/fonts.ts`
- Blogové články: `src/content/blog/*.mdx`
- Placeholdery k doplnění: `TODO-OBSAH.md`
